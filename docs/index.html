Formal Problem Formulation (PEAS & State Space)

The 4×4 15-Puzzle consists of 15 numbered tiles and one blank cell (0) in row-major order.

  • State Space Size: 16! / 2 = 10,461,394,944,000 reachable configurations.
  • Goal State: [1..15, 0]; Actions: {UP, DOWN, LEFT, RIGHT} blank moves.
  • Solvability Invariant: Reachable iff (inversions + blank_row_from_bottom) ≡ 1 (mod 2).
h1(s) = Σ [tile_i != 0 and tile_i != goal_i] (Misplaced Tiles, admissible)
h2(s) = Σ (|r_i - r*_i| + |c_i - c*_i|) (Manhattan Distance, consistent)
h3(s) = h2(s) + 2 × linear_conflicts(s) (Linear Conflict, dominant & consistent)

Darwinian Genetic Algorithm Formulation

Chromosomes encode fixed-length action sequences A = (a₁, a₂, …, a_L) evaluated sequentially with early termination when goal_test(s_t) becomes True.

conflict_count(s) = misplaced_tiles(s) + 2 × linear_conflicts(s) (0 ⇔ goal)

fitness(A) = LARGE_CONSTANT - path_cost if goal_test == True
= BASE_CONSTANT - (w_d·h + w_c·conflict + w_g·cost + w_inv·invalid) else
  • Selection: select(population) evaluates fitness internally and returns N/2 parent pairs via Roulette Wheel or k-Tournament (default k=4).
  • Operators: Single-Point / Two-Point Crossover + Point / Swap / Segment Mutation under a seeded PRNG.
